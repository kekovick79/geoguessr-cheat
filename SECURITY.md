# Security policy

## Reporting a vulnerability

Please report security issues privately to [support@geoboost.win](mailto:support@geoboost.win?subject=GeoBoost%20security%20report). Do not publish exploit details, license keys, account information or private user data in a GitHub issue.

Include the affected version, browser version, reproduction steps, expected behavior and observed behavior. GeoBoost will acknowledge a reproducible report and investigate it before public disclosure.

## Scope

This repository contains public documentation and media only. The production extension is distributed through the Chrome Web Store and its proprietary source code is not included here.
