# Contributing to the documentation

Corrections to public GeoBoost documentation are welcome.

Before opening a pull request:

1. Check the current Chrome Web Store version.
2. Reproduce product behavior on a supported private, practice or testing round.
3. Describe the exact game, mode, browser and extension version used.
4. Keep claims limited to what was directly observed.
5. Do not include extension source code, license keys, user data or payment information.

For product support rather than a documentation correction, use [support@geoboost.win](mailto:support@geoboost.win).
