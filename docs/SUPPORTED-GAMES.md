# Supported geography games

GeoBoost currently checks selected round workflows on five geography-game sites.

| Game | Supported product context | Important limitation |
|---|---|---|
| GeoGuessr | Private, practice and testing rounds | Not intended for ranked or competitive play |
| OpenGuessr | Supported private and casual round pages | Site updates can change available data and controls |
| WorldGuessr | Supported private and practice pages | Not every mode exposes the same round information |
| FreeGuessr | Supported casual round pages | Exact-point and placement support can vary |
| Geotastic | Supported private and testing pages | Map controls and page layouts can change |

## What “supported” means

A supported round is one where the current version of GeoBoost can detect the active round and provide the relevant result without reusing a prior round. A successful check on one game is not treated as proof that another game or mode works identically.

## Before relying on the extension

1. Install the current Chrome Web Store build.
2. Use the free guesses on the exact game and mode you plan to play.
3. Confirm that the location belongs to the active round.
4. Check that map preview and placement controls behave correctly.
5. Use helper features only when the rules of the round allow them.

For the repeatable product test process, read the official [GeoBoost testing methodology](https://geoboost.win/testing-methodology).
