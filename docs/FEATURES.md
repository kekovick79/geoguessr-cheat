# GeoBoost feature reference

GeoBoost is a Chrome side-panel extension for supported private, practice, testing and party rounds in geography games. This page documents the current behavior of the GeoGuessr cheat extension without promising support for every game mode or future website version.

## Exact coordinates and readable locations

When a round is supported, GeoBoost shows the current map point and its coordinates. Reverse geocoding can add a readable city, region or country label when that service is available.

## Map preview

The side panel displays the result on a compact map so the player can check the point before opening the full game map or placing a pin.

## Auto Place

Auto Place can place the detected point on supported game maps. It is available in the free and Pro workflows. Use automated placement only in contexts where helper tools are allowed.

## Smart Zoom

Smart Zoom moves and zooms the game map before the final placement. It is a Pro feature and depends on the map controls exposed by the active game mode.

## Range

Range offsets the final placement inside a selected score window. It is a Pro feature for private, practice and testing workflows that need a less-than-exact placement.

## Hotkey and side panel

The default hotkey is `G`. A different single key can be selected in extension settings. The hotkey is ignored while the cursor is inside an input field.

## Free and Pro access

The free path includes five starter guesses and then one free guess per day. Pro unlocks unlimited use, Smart Zoom and Range. Current pricing and access options are shown inside the extension and on the [GeoBoost pricing page](https://geoboost.win/pricing).
